# Portfolio BTS SIO SISR - Fayolle NKALOU

Ce dossier contient une version statique prête à héberger du portfolio E5 BTS SIO option SISR.

## Contenu

- `index.html` : page principale du portfolio
- `assets/style.css` : mise en forme
- `assets/script.js` : menu responsive et navigation active
- `robots.txt` : demande aux moteurs de recherche de ne pas indexer le site
- `sources.md` : liste des sources utilisées pour la veille

## Hébergement recommandé

### Option simple : Netlify Drop

1. Aller sur Netlify Drop.
2. Déposer le dossier `portfolio_nkalou_fayolle_site` ou le fichier ZIP.
3. Copier l'URL générée.
4. Coller cette URL dans le tableau de synthèse officiel, ligne "Adresse URL du portfolio".

### Option GitHub Pages

1. Créer un dépôt GitHub, par exemple `portfolio-bts-sio-sisr`.
2. Déposer tous les fichiers du dossier à la racine du dépôt.
3. Aller dans `Settings` > `Pages`.
4. Choisir `Deploy from a branch`, branche `main`, dossier `/root`.
5. Après publication, l'URL sera du type :
   `https://votre-identifiant.github.io/portfolio-bts-sio-sisr/`
6. Reporter cette URL dans l'annexe VI-1.

### Option Vercel

1. Créer un nouveau projet Vercel.
2. Importer le dossier ou le dépôt GitHub.
3. Laisser les paramètres par défaut pour un site statique.
4. Copier l'URL fournie.

## Points à vérifier avant publication

- Remplacer "À compléter après hébergement" par l'URL finale si souhaité.
- Ne pas ajouter de captures contenant des données internes ou personnelles.
- Vérifier que les sources de veille s'ouvrent correctement.
- Tester le site sur téléphone et ordinateur.
- Compléter l'adresse URL du portfolio dans le tableau de synthèse officiel.
